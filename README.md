# AIスライド構成案ジェネレーター

テーマ・ターゲット・目的・要点メモを入力すると、
Claude AIがGamma等へそのまま貼り付け可能な
Markdown形式のスライド構成案を生成するWebアプリです。

## 主な機能

- AIによるスライド構成案生成
- Markdown形式で出力
- Gammaへの貼り付け対応
- ターゲット・目的に応じた構成最適化
- Claude APIによる文章生成
- Webブラウザ上で利用可能

## 使用技術

- HTML / CSS / JavaScript
- Node.js
- Express
- Claude API
- Vercel

## デモ

[デモサイトはこちら](https://slide-generator-2.vercel.app/)

## 補足

AIを活用したプレゼン構成生成システムとして、
実験・運用しているプロジェクトです。
